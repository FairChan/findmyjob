# FindMYJob · 产品原型

马来西亚校园招聘平台的可交互前端原型：学生免费建档、投递；认证企业在人才库里按学校、语言能力、工作准证筛选人才，用点数解锁联系方式。

**在线体验：** https://fairchan.github.io/talentbridge-prototype/

> ⚠️ 这是产品原型，不是正式上线的服务。页面里的企业、人物、合作机构和数据全部是虚构的。没有后端，不收集任何信息，所有操作只保存在你自己浏览器的 localStorage 里。

## 怎么体验
页面左下角的「演示面板」可以切换四种身份：访客、学生、企业 HR、平台运营，也可以一键重置数据。

推荐路线：
1. **访客**：首页 → 职位页筛选「接受学生准证」→ 点「立即投递」
2. **学生**：投递后看「投递记录」；在「隐私中心」可以关闭人才库、屏蔽公司、查看谁看过我
3. **企业 HR**：「收到的简历」看板里拖动候选人；「人才库」打开一份档案，解锁前只显示姓氏，经历里的联系方式自动隐藏，解锁后显示全名和电话，可下载带水印的简历
4. **平台运营**：「系统设置」打开收费开关，企业端的套餐就可以购买了

## 本地运行

```bash
npm install
```

```bash
npm run dev
```

打开 http://localhost:5180 。`npm run build` 会把整个应用打包成一个 `dist/index.html`，可以直接双击打开。

## 技术栈
React 19 · TypeScript · Vite · Tailwind CSS 4 · React Router（HashRouter）· lucide-react

| 目录 | 内容 |
|---|---|
| `src/data/mock.ts` | 虚构的企业、职位、学生数据 |
| `src/store.tsx` | 全局状态和业务规则（投递、解锁、点数账本、屏蔽、审计） |
| `src/lib/privacy.ts` | 姓名脱敏、自由文本联系方式隐藏、档案完成度 |
| `src/pages/` | 公共页、学生端、企业端、运营后台 |

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
