# 职位展开弹窗与企业侧栏浏览

## 目标与范围

把用户提供的 Aceternity Expandable Card 交互用于登录后的「找职位」和「看企业」页面。职位卡片展开为详情弹窗；企业卡片被选中后，在页面右侧固定显示企业及其在招职位。企业本身不打开弹窗。

范围为 `/s/jobs`、`/s/companies` 及关联的会员职位详情。游客展示页继续提供精选内容和登录入口，企业招聘管理及运营后台不增加这套浏览交互。本次完成后沿用现有发布流程部署。

## 方案选择

| 方案 | 取舍 |
| --- | --- |
| 推荐：路由弹窗复用服务端职位详情，企业使用页面内侧栏 | 支持职位链接分享、刷新和前进后退；保留服务端权限及查看额度。需要少量并行路由文件。 |
| 仅客户端弹窗，另建详情取数接口 | 局部交互简单，但需额外维护 URL、历史记录、错误处理和取数权限。 |
| 点击卡片继续进入整页详情 | 维护最少，但不能满足用户希望保留列表并展开阅读的交互。 |

采用第一种方案。复用已安装的 Motion 与 Radix Dialog，参考附件的展开、遮罩和收起效果，使用真实职位内容和项目现有视觉令牌。

## 职位页面

- 保留顶部会员导航、关键词搜索、各项筛选、重置与分页。职位卡片按手机一列、平板两列、宽桌面三列排列，列表容器在宽屏适度扩展。
- 卡片显示企业、职位标题、类型、工作方式、地点、签证标签及允许展示的薪资。卡片高度和留白统一；焦点与悬停使用边框、底色和轻微阴影。
- 点击卡片后，卡片的圆角轮廓与标题区域平滑展开为居中的详情弹窗，列表保留在遮罩后。弹窗最大高度受视口约束，正文内部滚动，手机保留边距并提供足够大的关闭按钮。
- 弹窗使用现有服务端职位详情，保留薪资、要求、福利、投递、分享、举报、已投递状态及额度不足提示。正文在弹窗中使用紧凑布局，投递入口容易找到。
- 弹窗地址为真实 `/s/jobs/[id]`。关闭或浏览器后退恢复原列表、筛选及滚动位置；前进可重开。直接打开或刷新详情链接展示完整详情页，并保留会员导航。
- 使用 Next.js 截获路由与并行路由承载弹窗，默认及其他页面的槽位返回空内容，避免切页后残留弹窗。列表至详情的链接禁止预取，实际打开时才执行原有额度逻辑。
- 详情中的企业入口导向 `/s/companies?company=[id]`，进入企业页并选中对应企业。

## 企业页面

- 保留企业标签筛选与企业分页。主要区域改为左侧企业卡片网格、右侧企业职位面板，替换会员页面原有的重复轮播／企业弹窗区域。
- 宽屏左侧以两列卡片展示企业 Logo、名称、地点和职位数量。选中卡片有清晰边框及选中状态，点击后仅更新右侧内容。
- 右侧面板在顶部导航下方保持可见，显示企业 Logo、名称、简介、地点、官网与在招职位；内容超出可视高度时可独立滚动。职位仍使用真实标题、标签及允许展示的薪资。
- 默认选中当前列表第一家企业；URL 的 `company` 参数可以指定有效、已审核且启用的企业。筛选或翻页会选择新列表第一家，避免右侧与当前列表产生歧义。外部指定的有效企业可以单独加载，其标题明确说明当前选中对象。
- 企业选择写入 URL，并保留当前标签与企业分页参数；服务端查询并校验企业资格，只返回公开企业字段及已发布、未过期职位。切换时显示加载状态，失效企业显示明确提示，并允许继续选择。
- 右侧职位独立分页，使用不同于企业分页的参数；切换企业时重置职位页。没有职位时显示空态。
- 点击右侧的职位打开同一职位详情弹窗；关闭后恢复当前企业、职位页与企业列表。
- 手机及窄屏将企业面板放在网格下方，选择企业后滚动到面板并提示选中结果；不将企业内容变成弹窗，也不产生水平溢出。
- 旧 `/s/companies/[id]` 直达链接继续可用。

## 可访问性与视觉

- 沿用现有白色／浅灰表面、蓝色强调、圆角卡片、中英文字体和间距令牌。参考 ui-ux-pro-max 的平台／教育卡片层次及 React、Next.js、shadcn 指导，不更换整站字体或主题。
- 弹窗有可读标题、焦点约束、关闭按钮，支持 Escape 与点击遮罩关闭，关闭后焦点返回打开它的卡片。嵌套投递／举报弹窗先处理自身的 Escape，避免同时关闭外层。
- 背景滚动锁定在关闭、路由变化及异常路径均能恢复。加载、错误、失效职位及额度不足状态均在弹窗中明确展示，并保留退出路径。
- 尊重 `prefers-reduced-motion`，减少动态效果时跳过共享位置与尺寸动画。键盘焦点清晰，触摸目标至少 44px，长标题和无 Logo 企业仍能正常展示。

## 数据与安全边界

- 列表及企业侧栏不预载职位受限描述、联系方式、简历或其他私人字段。职位详情只复用已有权限、序列化与 `openJob` 流程。
- 保留学生身份、企业启用／审核状态、职位发布／截止状态、薪资可见性及投递校验。打开企业侧栏不消耗职位详情额度；打开具体职位才执行额度检查，重复打开沿用原规则。
- 不增加数据库迁移和新的第三方依赖。

## 验收与交付

1. 验证职位多列布局、展开／关闭、URL、前进后退、刷新直达与搜索／分页状态恢复。
2. 验证企业切换、选中样式、右侧固定面板、企业／职位分别分页、空态和过期数据。
3. 验证职位投递／举报嵌套弹窗、键盘／Escape／焦点恢复、减少动态效果、中英文及 375px 布局。
4. 回归查看额度、隐藏薪资、公开数据边界、身份重定向、会员导航及旧详情链接。
5. 通过针对性的集成／浏览器测试、lint、类型检查和生产构建后，检查代码差异并部署到 `findmyjob.asia`；验证线上页面与服务健康，保留可回滚版本。

## 设计自检

本设计区分了职位弹窗与企业页面内面板，明确默认选择、移动布局、URL、分页与额度触发时机。所有展示均基于现有业务数据，无占位交互或待定项。
